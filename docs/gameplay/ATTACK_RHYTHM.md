# 进攻节奏配置与局内操作

游戏每 30 毫秒推进一个逻辑 tick。默认六波阵容嵌入在 `26C-/attack_waves.json`，共 90 个敌人；最终波 Boss 后的 18 个敌人作为增援事件显示，但类型、数量、路径轮换和奖励都沿用原规则。

若要调整节奏，把构建目录中的 `attack_rhythm.example.json` 复制为与 `final.exe` 同目录的 `attack_rhythm.json`，再修改数值并开始新局。每次新局都会重新读取；文件不存在时使用内置节奏。文件有错误时整份配置不生效，游戏显示提示并使用内置节奏。示例只调整第一波，另外五波的 `{}` 表示保持默认。

`waves` 必须是六个对象，`version` 必须为 `1`。每个波次对象可覆盖以下字段，单位均为 tick：

| 字段 | 作用 | 范围 |
| --- | --- | --- |
| `openingDelayFrames` | 该波开始到首个敌人的时间 | 1–10000 |
| `openingBurstSize` | 开场小队规模 | 1–10，且不大于 `burstSize` |
| `spawnIntervalFrames` | 后续小队的最低起始间隔 | 1–10000 |
| `burstSize` | 后续每组最多几个敌人 | 1–10 |
| `burstGapFrames` | 组内相邻敌人的间隔 | 1–10000 |
| `clearThreshold` | 本波发完后，场上敌人不多于此数才开始切波倒计时 | 0–90 |
| `nextWaveDelayFrames` | 达到清场条件后到下一波开始的等待次数 | 1–10000 |

同一组的首个敌人到下一组首个敌人的间隔为 `max(spawnIntervalFrames, 组规模 × burstGapFrames + 1)`。只接受有限整数；外部文件不能修改敌人阵容、Boss 位置或增援构成。内置节奏特意保留原版第 5 波小队计数延续到第 6 波所造成的实际开场时序，第 6 波首怪在切波后第 9 tick 出现。

局内点击右上角“预览”可查看最多三个即将执行的事件及倒计时，增援会单独标记。点击“暂停”或按 `P`/`Esc` 停止游戏计时和对战音乐；点击“继续”或再次按键恢复。点击“退出”放弃当前局并返回菜单。`1`/`2`/`3` 选塔，`U` 升级，`X` 出售；暂停时这些操作不可用。移动鼠标可预览建塔位置：绿色可建，红色表示道路、占用或金币不足。画面底部点击会吸附到最后一行可见网格。
